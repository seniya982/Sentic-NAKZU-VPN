# ⚡ Sentic NAKZU v1 - Advanced VPN Client

**Sentic NAKZU v1** is a remastered, highly optimized network and VPN client powered by **Sentic Hosting**. Built upon the robust core of Netch, this customized client features an ultra-modern dark aesthetic, live telemetry integrations, and seamless performance for secure browsing, gaming, and professional use.

📥 **[Download Sentic NAKZU v1 Now](https://github.com/seniya982/Sentic-NAKZU-VPN/releases/tag/v1.0.0)**

## ✨ Key Features
* **Ultra-Modern UI:** Completely redesigned with a customized Dark Slate (`#050B14`), Neon Blue, and Dark Orange aesthetic for a premium, futuristic feel.
* **Live Analytics API:** Integrated background telemetry for real-time connection monitoring via the Sentic Admin Dashboard.
* **Session Tracking:** Built-in connection timer with dynamic UI states and automated config reporting.
* **Portable & Self-Contained:** Compiled as a single executable. Runs instantly without requiring manual .NET runtime installations.
* **Multi-Protocol Support:** Fully supports V2Ray, VMess, VLESS, Shadowsocks, ShadowsocksR, Trojan, and custom routing modes.

## 🚀 Installation & Usage
1. Download the latest `Sentic-NAKZU.exe` from the **Releases** section.
2. Run the application as **Administrator** (Required for correct network routing).
3. Import your VPN configuration (e.g., `vless://...`) or subscribe to Sentic Hosting nodes.
4. Select your Mode (e.g., `[3] Bypass LAN`) and click **Start**.
